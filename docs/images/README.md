# Screenshot Assets Guide

This directory contains visual screenshot placeholders and media assets for the Prometra repository documentation.

## Expected Screenshots

- `dashboard.png`: Screenshot of `prometra dashboard` rich terminal analytics layout.
- `search.png`: Screenshot of `prometra search` instant search results with highlighted matches.
- `timeline.png`: Screenshot of `prometra timeline` interactive visual event table.
- `diff.png`: Screenshot of `prometra diff` colorized file version diff viewer output.
- `compare.png`: Screenshot of `prometra compare` side-by-side session comparison table.

## Asset Requirements

- Format: PNG / WebP
- Standard width: 1200px
- Theme: Dark terminal theme (Rich terminal output preferred)
