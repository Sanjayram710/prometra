# Prometra v1.9.0 Release Notes

**Release Date:** July 23, 2026

Prometra v1.9.0 introduces **Session Comparison**, allowing developers to compare two recorded development sessions side-by-side to evaluate productivity, code churn, and AI tool usage.

---

## What's New in v1.9.0

### 1. Session Comparison CLI (`prometra compare`)

Compare any two development sessions or inspect the latest two sessions automatically:

```bash
# Compare specific session IDs
prometra compare SESSION_A SESSION_B

# Compare the latest two sessions
prometra compare --latest

# Export comparison in JSON or Markdown format
prometra compare --latest --json
prometra compare --latest --markdown --export docs/compare_report.md
```

### 2. Side-by-Side Metrics & Productivity Insights

Session comparison aggregates and highlights:
- **Files Created, Modified, and Deleted**
- **Git Commits & AI Events**
- **Total Event Distribution & Timeline Differences**
- **Productivity Statistics**: Events per minute, files changed per minute, commits per hour.

### 3. Local-First Engine & Performance

- Operates 100% locally on local SQLite database history.
- Executes sub-75ms comparisons.

---

## Upgrade Guide

Upgrade via `pip`:

```bash
pip install --upgrade prometra
```

Verify version:

```bash
prometra version
# Output: Prometra Version: 1.9.0
```
