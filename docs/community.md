# Prometra Community Guidelines

Welcome to the Prometra community! We are thrilled to have developers, contributors, and open-source enthusiasts building the future of local-first developer intelligence together.

---

## Community Communication Channels

### 1. GitHub Discussions

We use **GitHub Discussions** as our central hub for community conversations, Q&A, and technical architecture proposals:

- **Q&A**: Ask how to configure Prometra, write custom connectors, or integrate `.prometraignore`.
- **Ideas & RFCs**: Discuss prospective feature proposals before opening formal pull requests.
- **Showcase**: Share how your team uses Prometra in your local workflows.

### 2. GitHub Issues

Use **GitHub Issues** strictly for actionable work items:

- **Bug Reports**: Unexpected runtime errors, failing CLI commands, or data persistence anomalies. Please use the [Bug Report Template](../.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: Specific, well-defined CLI additions or API proposals. Please use the [Feature Request Template](../.github/ISSUE_TEMPLATE/feature_request.md).

---

## How to Get Help

1. **Check Documentation**: Review our comprehensive documentation guides in `docs/` (`cli.md`, `search.md`, `diff.md`, `compare.md`, `dashboard.md`, `timeline.md`, `replay.md`).
2. **Search Discussions & Issues**: Check if your question or bug has already been resolved in past threads.
3. **Open a Discussion Thread**: If you need advice on setup or architecture, create a new thread in GitHub Discussions.

---

## Contributing to Community Growth

- Star the repository on GitHub to support our open-source visibility.
- Share Prometra with your development team.
- Contribute connector integrations (e.g., custom AI assistant connectors) using our [Connector SDK](connectors.md).
